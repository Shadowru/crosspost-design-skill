# Как перестать переписывать статью четыре раза

:::tldr
- Пишем один исходный текст, а не четыре версии.
- Разметка каждой площадки — это белый список тегов, а не вкусовщина.
- Всё, что площадка не умеет, деградирует осознанно и попадает в отчёт.
:::

Редактор, который ведёт четыре площадки, тратит на перенос текста больше времени, чем на сам текст. Причём тратит его на самое скучное: заново расставить подзаголовки, заново собрать список, заново вставить картинки.

<!--cut-->

## Почему копипаст не работает

У каждой площадки свой белый список разметки, и он куда уже, чем кажется. ==Инлайновый CSS не переживает ни одну из них==, а половина привычных элементов просто исчезает при вставке.

> Правило простое: то, чего нет в белом списке, исчезнет молча. Задача редактора — решить, чем это заменить, до публикации, а не после.

| Площадка | Заголовки | Код | Таблицы |
| --- | --- | --- | --- |
| Telegram IV | h3, h4 | есть | нет |
| VK | два уровня | нет | нет |
| Дзен | h2–h4 | нет | нет |
| Habr | h1–h3 | есть | есть |

## Что делает единый исходник

Исходный текст хранит **смысл**, а не оформление. Дальше сборщик решает, как этот смысл показать на конкретной площадке.

1. Разбираем текст в дерево блоков.
2. Для каждой площадки применяем её карту разметки.
3. Всё, что не поместилось, пишем в отчёт.

> [!NOTE] Про деградацию
> Деградация — это не потеря. Это осознанный выбор замены: таблица становится списком, код — цитатой с неразрывными пробелами.

Вот минимальный вызов сборщика:

```bash
python3 scripts/build_targets.py article.md -o out -p telegram,vk,dzen,habr
```

## Что остаётся человеку

Машина не придумает лид, не выберет три главных тезиса и не решит, какой абзац лишний. Всё остальное — механика, и её незачем делать руками.

[^1]: Instant View собирается по шаблону правил для конкретного домена; telegra.ph — исключение, для него шаблон уже есть.
