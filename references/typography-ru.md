# Русская микротипографика

На всех четырёх площадках CSS вырезается, а **Unicode остаётся**. Поэтому
типографика — единственный слой оформления, который переживает публикацию
целиком. Пишите сразу правильно: `typography_lint.py --fix` — страховка, а не
основной инструмент.

## Обязательное

| Правило | Неправильно | Правильно |
|---|---|---|
| Кавычки — «ёлочки» | `"текст"` | `«текст»` |
| Вложенные — „лапки“ | `«внутри "вложенная" цитата»` | `«внутри „вложенная“ цитата»` |
| Тире — длинное | `слово - слово` | `слово — слово` |
| Дефис только внутри слова | `кто — то` | `кто-то` |
| Диапазоны — среднее тире | `5-7 дней` | `5–7 дней` |
| Многоточие — один символ | `...` | `…` |
| Нет пробела перед знаком | `слово , слово` | `слово, слово` |
| Есть пробел после знака | `слово,слово` | `слово, слово` |
| Один пробел между словами | `слово␣␣слово` | `слово слово` |

## Неразрывные пробелы (`--nbsp`)

Ставятся так, чтобы строка не заканчивалась «висящим» словом:

- после предлогов и союзов из 1–3 букв: `в␣Москве`, `и␣тогда`, `для␣того`;
- перед длинным тире: `слово␣— слово`;
- между числом и единицей: `10␣кг`, `5␣%`, `№␣3`;
- внутри сокращений: `т.␣е.`, `и␣т.␣д.`, `2024␣г.`

Линтер делает это только с флагом `--nbsp` — по умолчанию он молчит, потому что
для коротких постов связок бывает слишком много.

## Тонкости, которые линтер не исправит

- **Ё.** В обычной статье пишите `ё` там, где без неё меняется смысл (`всё` /
  `все`, `небо` / `нёбо`). Сплошная `ё` уместна в детском и учебном тексте.
- **Тире vs дефис в заголовках.** В заголовке лучше двоеточие, чем тире:
  `Инструменты: что выбрать` читается быстрее, чем `Инструменты — что выбрать`.
- **Кавычки в кавычках названий.** `сервис «Дзен»` — да; `сервис "Дзен"` — нет;
  латинские названия кавычек не требуют: `сервис Notion`.
- **Проценты.** `5 %` (с неразрывным) — норма русской типографики; `5%` тоже
  встречается, но выберите одно на всю статью.
- **Числительные.** До десяти — словами в связном тексте (`три способа`), цифрами
  — в списках, таблицах и там, где число само по себе значимо.
- **Восклицательные знаки.** Один на статью — уже много. `!!` не бывает.
- **КАПС.** Не выделение, а крик. Выделяйте жирным.

## Что делать с заимствованиями и кодом

- Внутри `` `кода` ``, блоков кода, URL и `{{плейсхолдеров}}` типографика **не
  применяется** — линтер их маскирует.
- Английские названия не склоняем через дефис: `в Telegram`, не `в Telegram-е`.
- Аббревиатуры в русском тексте пишем как есть: `HTML`, `RSS`, `API`.

## Проверка

```bash
scripts/typography_lint.py article.md              # отчёт
scripts/typography_lint.py article.md --fix        # исправить
scripts/typography_lint.py article.md --fix --nbsp # + неразрывные пробелы
```

Предупреждения (`!`) требуют решения человека: повторные `!?`, капс, оставшаяся
одиночная прямая кавычка.
